## 👤 Perfil

Combino ingeniería industrial con datos y programación para mejorar la planificación, la producción y el abastecimiento. Este perfil es mi portfolio de proyectos.

## 🎯 Áreas de interés

- **Planeamiento y abastecimiento:** stock, reposición y necesidades de materiales.
- **Producción y operaciones:** programación, dotación y eficiencia de línea.
- **Mejora continua:** Lean, mapeo de procesos e indicadores.
- **Automatización y análisis de datos:** Python y Excel aplicados a tareas operativas.

## ✅ Cómo trabajo

- **Números verificables:** los cálculos salen de código con pruebas, no de estimaciones a ojo.
- **Supuestos explícitos:** cada dato dice de dónde sale, y lo real se distingue de lo sintético.
- **IA como apoyo:** asiste y propone; las decisiones las toma una persona.
- **Sin datos confidenciales:** los proyectos usan datos propios, públicos o sintéticos.
